# Quora Question Classification Using NLP and Machine Learning

## Project Overview

This project classifies Quora questions as **Sincere** or **Insincere** using Natural Language Processing (NLP) and Machine Learning techniques.

The project involves:

* Text preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering

  * Bag of Words (BoW)
  * TF-IDF
* Machine Learning Models

  * Logistic Regression
  * XGBoost
* Model Evaluation

  * ROC-AUC
  * Confusion Matrix
  * Classification Report

## Dataset

Quora Insincere Questions Classification Dataset from Kaggle.

Dataset Link:
https://www.kaggle.com/competitions/quora-insincere-questions-classification

## Models Implemented

### Logistic Regression with TF-IDF

Used TF-IDF features with hyperparameter tuning using GridSearchCV.

### Logistic Regression with Bag of Words

Used CountVectorizer and Logistic Regression.

### XGBoost

Implemented XGBoost with RandomizedSearchCV for parameter tuning.
